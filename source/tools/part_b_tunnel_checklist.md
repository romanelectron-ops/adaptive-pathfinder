# Часть B3 — Реальный туннель и leak-тесты (ручной чек-лист)

Отметь каждый пункт. Это проверяет то, что Claude не может: фактический трафик и утечки.

## Подготовка
- [ ] sing-box бинарь на месте (bin/), есть рабочий узел или подписка.

## Импорт (3 формата — F-12, B-12.2)
- [ ] Импорт по ссылке (vless://, trojan://, ss://) — узел добавился.
- [ ] Импорт sing-box config.json (outbounds) — узлы извлеклись, служебные пропущены.
- [ ] Импорт Clash YAML (proxies:) — узлы извлеклись.
- [ ] Импорт мусора — НЕ падает, показывает понятную ошибку.

## Подключение и смена IP
- [ ] Connect → статус Connected.
- [ ] Внешний IP сменился (ifconfig.me / whatismyipaddress.com) — НЕ твой ISP.

## Утечки
- [ ] DNS leak (browserleaks.com/dns) — DNS через туннель, локальный ISP не виден.
- [ ] WebRTC (browserleaks.com/webrtc) — APF честно показывает "partial" (T-13б);
      применить браузерную инструкцию из /api/leakguard/browser-instructions и перепроверить — утечки нет.
- [ ] IPv6 (test-ipv6.com) — если IPv6-guard вкл., IPv6 не течёт мимо туннеля.

## Pin (F-30)
- [ ] Закрепить узел → запустить авто-скан → остаётся на закреплённом, не перепрыгивает.

## ShadowTLS / CDN (если настроен сервер) — T-18
- [ ] Включить ShadowTLS → Connect → туннель встаёт; в логах sing-box виден shadowtls-outbound.
- [ ] Включить CDN-fronting → Connect → трафик идёт на CDN IP, SNI = фронт-домен.

## Fallback (T-16б)
- [ ] Заблокировать основной узел → APF проходит L1→L4, восстанавливает связь.
- [ ] При отсутствии psiphond — лог честно говорит "Psiphon недоступен — Tor" (не маскирует).

## Стабильность (T-25)
- [ ] Долгая сессия (1–2 часа, несколько переключений) → процесс стабилен, память/CPU не растут бесконтрольно.
- [ ] Stop/выход → все фоновые задачи завершились, процесс закрылся чисто (не висит).
