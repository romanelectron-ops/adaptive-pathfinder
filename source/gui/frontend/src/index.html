▸ Как пробросить порт на роутере (если автоопределение выше не помогло) ?
Какой способ ваш?
  • Домашний роутер (кабель ИЛИ WiFi): проброс порта по инструкции ниже. Если этот компьютер подключён по WiFi, дополнительно закрепите за ним статический локальный IP (DHCP-резервирование по MAC в роутере, либо статика в настройках сети) — иначе правило проброса перестанет работать, когда IP сменится. Кабель или WiFi для самого проброса роли не играет: правило создаётся на роутере и указывает на локальный IP этого компьютера.
  • Мобильный интернет (4G/5G-модем, телефон/ноут через оператора): проброс порта, скорее всего, не сработает — операторы почти всегда за CGNAT (серый IP, публичного нет, роутер оператора вам не подконтролен). Используйте relay-посредник (поля «Адрес relay-сервера» и его отпечаток в «Необязательных параметрах» ниже): и «Выход», и партнёр-«Вход» соединяются исходяще к relay с белым IP — проброс не нужен. Relay — любая точка с публичным IP (ваш VPS / Raspberry Pi с белым IP / дешёвый облачный тариф). Исключение: платная услуга «белый/статический IP» у оператора — тогда можно и напрямую.
Общие шаги (для любого роутера):
  1. Порт для проброса — тот же, что в поле «Порт» выше (по умолчанию 8443).
  2. Узнайте локальный IP ЭТОГО компьютера в вашей сети (Windows: командная строка → ipconfig → строка «IPv4-адрес») — именно на него роутер должен направлять входящие подключения.
  3. Зайдите в веб-интерфейс роутера — обычно http://192.168.1.1 или http://192.168.0.1 (адрес часто написан на наклейке снизу роутера), войдите под логином/паролем администратора (тоже часто на наклейке).
  4. Найдите раздел проброса портов — называется по-разному в зависимости от прошивки: «Переадресация портов», «Port Forwarding», «Виртуальные серверы», «Virtual Server», «NAT» (см. вашу модель в списке ниже).
  5. Создайте правило: внешний (WAN) порт = внутренний (LAN) порт = порт из поля «Порт» выше; протокол — TCP; внутренний IP — локальный IP этого компьютера из шага 2.
  6. Сохраните правило; если роутер просит — перезагрузите его.
  7. Проверьте: нажмите «Определить автоматически» выше ещё раз, либо попросите партнёра «Вход» попробовать подключиться по готовой ссылке (см. Шаг 3 ниже).
Пошагово для конкретной модели (черновик — сверяйтесь с реальными названиями в вашей прошивке, они могли измениться):
Выберите модель роутера из списка выше — или следуйте общим шагам, если вашей модели нет в списке.

Сеть и прокси
Системный прокси?
Направлять трафик обычных приложений через локальный прокси APF. В режиме прокси нужен ОБЯЗАТЕЛЬНО, если включён Kill Switch — иначе Kill Switch заблокирует весь интернет, а не только цель.
Bypass-правила?
Домены, которым нужен особый маршрут
Прямой маршрут?
Домен идёт МИМО VPN целиком (не резидентский-предпочтительный, а буквально в обход туннеля) — не защищён VPN. Выключено — домен всё ещё идёт через VPN, просто предпочитается резидентский IP.
