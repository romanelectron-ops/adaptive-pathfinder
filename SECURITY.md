# Безопасность

## Как сообщить об уязвимости

Пожалуйста, **не публикуйте** уязвимость в открытых Issues. Используйте закрытое сообщение
через GitHub: вкладка **Security → Report a vulnerability** этого репозитория.

Укажите версию, платформу, шаги воспроизведения и возможные последствия. Мы постараемся
ответить как можно быстрее.

## Что важно знать о текущих сборках

- Сборки **не подписаны** сертификатом издателя. Скачивайте их только со страницы
  Releases этого репозитория и сверяйте SHA-256 с приложенным файлом сумм.
- Встроенная проверка обновлений только **уведомляет** о новой версии; само приложение
  файлы не заменяет, пока релизы не подписаны.
- Локальный HTTP API слушает только `127.0.0.1` и требует токен доступа.
- Роль «Выход» открывает порт на вашем устройстве. Давайте ссылку только тем, кому
  доверяете: трафик подключившихся уходит в интернет с вашего адреса. Число одновременных
  подключений ограничено.
